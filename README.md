# 📜 نزهة المشتاق في اختراق الآفاق

### للشريف الإدريسي - عرض وتوثيق

## 📌 حول المشروع
هذا المشروع يعرض كتاب **«نزهة المشتاق في اختراق الآفاق»** للشريف الإدريسي، مع الحفاظ التام على هيكله الأصلي:
- **7 أقاليم مناخية**
- كل إقليم مقسم إلى **10 أجزاء** بالترتيب الأصلي
- التنقل من الغرب إلى الشرق ابتداءً من المحيط الأطلسي وانتهاءً ببحر الصين

## ⚠️ تنويه هام
- النص المعروض مأخوذ من **الطبعة المطبوعة المحققة**: طبعة عالم الكتب - بيروت 1409هـ/1989م.
- قد يختلف هذا النص قليلاً عن المخطوطات اليدوية الأصلية المحفوظة في المكتبات العالمية.
- أي قسم بعنوان **«عرض حديث»** هو عمل مستوحى من منهج الإدريسي، **وليس جزءاً من الكتاب الأصلي**.
- الأجزاء التي لم يُكتمل نصها الحرفي موسومة **«قيد الإضافة»**، ولم يتم اختلاق أو إضافة أي نص غير مؤكد؛ يُستكمل من المصادر الموثوقة.

## 📂 هيكل الملفات

```
├─ index.html       ← الواجهة والتنقل
└─ all-regions.js    ← بيانات الأقاليم والأجزاء
```

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعاً باسم `nuzhat-al-mushtaq` (Public) مع إضافة README.
2. ارفع الملفين: `index.html` و `all-regions.js`.
3. فعّل GitHub Pages من Settings → Pages → مصدر `main` → `/root`.
4. انتظر 1–3 دقائق.
